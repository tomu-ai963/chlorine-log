# 残留塩素 検査記録

集落の簡易水道で行う残留塩素の毎日の検査結果を、紙の検査表と同じ形式で入力し、月ごとにメールで提出するためのWebアプリです。`index.html` 1枚で動き、ビルドやサーバーは不要です。

## できること

- 年月を選ぶと、その月の日付と曜日の表を自動で作成
- 時間の入力（「今」ボタンで現在時刻を入力し、濁度・色度・臭いの空欄を ◯ にする）
- 残塩を小数で入力（0.1以下・0.6以上は赤く表示し、メール本文にも「基準外」としてまとめる）
- 濁度・色度・臭いはタップで ◯ → ✕ → 空欄 を切り替え
- 備考欄
- 送信先を入れて「メールアプリで開く」で件名・本文入りのメールを作成。開かない場合は「本文をコピー」

## データの保存

入力内容・集落名・氏名・送信先はブラウザの localStorage に保存されます。サーバーには送信されません。保存先はそのブラウザだけなので、別の端末やブラウザとは共有されません。

## 使い方

`index.html` をブラウザで開くか、GitHub Pages で公開して使います。
